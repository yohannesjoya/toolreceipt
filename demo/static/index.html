Your agent says it sent the email. Did it?

LLM agents sometimes report actions that failed or never happened. toolreceipt records every tool call during a LangGraph run, reads the final reply, and flags each claim that has no successful call behind it.

STEP 1RecordA callback logs each tool call with its args and whether it succeeded.
STEP 2Read the replyRules pick out action claims like “sent a confirmation email”. No second LLM.
STEP 3CompareEach claim is matched to a call. Claims with no successful call are flagged.

    What your code gets back: receipt.verdict, receipt.ok and the lists below. Block, annotate or log the reply based on it.

    Reference

    The three verdicts

    clean

    Every claim matches a successful call, and every call is mentioned.

    ok = True

    unreported

    Claims all check out, but some tools ran without being mentioned. Usually fine, like a silent order lookup.

    ok = True

    fabricated

    The reply claims an action whose call failed or never happened.

    ok = False

    Add it to your agent

    # pip install "toolreceipt[langgraph]"
from toolreceipt import Receipts
from toolreceipt.langgraph import final_reply

rc = Receipts()
result = graph.invoke(inputs, config=rc.config())
receipt = rc.check(final_reply(result))

if not receipt.ok:
    ...  # block, annotate or log

    What it does not catch

    • English replies only, matched by rules. Unusual phrasing can be missed.
    • It checks that a call succeeded, not that its result was right.
    • When it cannot tell which tool a claim means, it marks the claim grey and does not flag it. It would rather miss one than cry wolf.
